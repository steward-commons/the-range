# Courses

A course is a JSON list of round ids with the lane, the expected result (`flag`, `quarantine`, `fail-safe`, `refuse-cleanly`, or `pass` for no-shoot plates), and a plate size (`big`, `small`, `holo`, `no-shoot`).

Only `practice.json` ships, built from the blank rounds. Write your own lane courses (`close-in.json`, `long-gallery.json`, `grenade-pit.json`, `sci-fi.json`) and a 40-round `qual-v1.json` from your own sealed rounds. Keep them private: a course list is a battle plan.
